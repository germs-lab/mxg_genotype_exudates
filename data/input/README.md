# Input Data

Raw LC-MS metabolomics data for Miscanthus genotype root exudates.

## Source

- **Provider**: Paul Abraham, Oak Ridge National Laboratory (ORNL)
- **Original structure**: `CBI_SRO_Howe/LC-Metabolomics/Data/`
- **Project**: Miscanthus genotype exudate characterization study

The data was originally provided as `LC-Metabolomics.zip` and has been extracted and organized into the current structure for analysis.

## Directory Structure

### Aqueous Fraction (`Aqueous_fraction/`)

LC-MS data for the aqueous (polar) fraction of root exudates. Contains water-soluble metabolites including:
- Organic acids
- Amino acids
- Sugars
- Other hydrophilic compounds

### Organic Fraction (`Organic_fraction/`)

LC-MS data for the organic (non-polar) fraction of root exudates. Contains lipophilic metabolites including:
- Fatty acids
- Lipids
- Phenolic compounds
- Other hydrophobic compounds
